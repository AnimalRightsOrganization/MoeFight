# MoeFight

## CS共享项目设置

1. VS → 工具 → 选项 → [搜索Unity]
	a. → 访问项目属性 False → True，使解决方案右键可显示属性。
	b. → 禁止完整生成项目 True → False，使编译Unity时生成dll（正常项目速度变慢）。
2. 所有引用项的复制本地 True → False。

## 规则

- 时长
  - 比赛90秒
  - 训练无限∞
- 帧率（tickrate）
  - 60
- 暂停
	- 每局1次，每次30秒。
- 断线重连
	- PING > 300ms，被服务器踢回大厅。提示调整网络或弃权。
	- 移除高PING玩家，CSGO、塔科夫等常用策略。
	- 断线后，60秒内重连，超时判负。
	- 房间内等待的玩家可解散比赛，不计分。
	- [S] 登录校验后，服务器判断是否是比赛中掉线的玩家。
	- [C] 进入大厅。
	- [S] 是重连玩家，就下发房间信息，提示是否返回？
	- [C] 弹窗是否返回。
	- [S] 选择返回比赛，再下发比赛帧。
	- [C] 弹出UI_Versus。追帧组装完比赛数据后，跳转场景。
	- [C] 弹出倒计时3、2、1恢复比赛。
